# Новый дизайн (по макетам)

Страницы собираются по макетам из Claude Design: https://claude.ai/artifact/LoQpGiXCVV1zyBAChMmkd5

- `tr.css` — стили макетов. Файл сгенерирован из `project/tr.css` макетов: все селекторы ограничены классом `.tr`, названия `@keyframes` получили префикс `tr-`, чтобы стили не влияли на страницы со старым дизайном. Руками не правится: обновляется перегенерацией из макетов.
- `home.css` — раскладка главной: компьютер (макет `d-home`) и телефон (`m-home`) в одном компоненте, граница 760 px.
- `shell.tsx` — стеклянная шапка, подвал и экран меню для телефона.
- `home.tsx` — главная страница. Карточки репетиторов берутся из текущего каталога (`src/entities/teacher`).
- `links.ts` — адреса ссылок. Пока готова только главная, поэтому «Вход», «Регистрация» никуда не ведут, а «Создать заявку» и «Помощь» ведут на страницу контактов.
- Цена на карточках: `PRICE` + 10% сервисного сбора (как в макете); отзывов и оценок пока нет, поэтому на карточках стоит «новый».

## Экраны-болванки

`screens/*.html` — выгрузка остальных экранов макета (компьютерная и телефонная версии каждого), показывается по адресу `/screens/<имя>`. Там, где нужен бэкенд, это статичные экраны без данных и действий: ссылки между ними работают, формы нет. Страница `/for-repetitor/` собрана из такой же выгрузки (`screens/tutors.*.html`). `screens/index.json` — названия экранов.

Выгрузка получена скриптом из макетов; после неё внесены правки продукта: нет сервисного сбора 10% в текстах для учеников, у знакомства нет фиксированной длительности (её выбирает репетитор), нет избранного. Для прямых ссылок на `/screens/*` в `vercel.json` есть перенаправление на `index.html`.
