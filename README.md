# TopRepet

Сайт сервиса частных репетиторов. React 19, TypeScript, React Router 7, Redux Toolkit, Vite 8. Все занятия: 1 200 ₽ / 60 минут. Бесплатное короткое знакомство. Контакт: https://t.me/a17xey.

## Запуск

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm build
pnpm start
```

## FSD

- src/app — провайдеры, роутер, store, общие стили.
- src/pages — главная, выбор занятий, перенаправление старых ссылок.
- src/widgets — самостоятельные блоки страницы.
- src/widgets/teachers — горизонтальная лента молодых преподавателей с раскрывающимися достижениями и Telegram-контактом.
- src/features/select-lesson — Redux Toolkit и интерфейс выбора цели, предмета, класса и экзамена.
- src/entities/lesson — каталог, типы и правила совместимости параметров.
- src/shared — цена, контакт, бренд и общие UI-адаптеры.

Зависимости направлены вниз по слоям. Адаптеры RadioGroup и Accordion используют имеющиеся компоненты из components/ui. В сборку попадают только используемые модули. Сайт статический, базы данных и контактных форм нет.

## Маршруты

- /#/ — главная.
- /#/lessons — выбор занятий.
- /#/lessons?goal=homework — домашние задания.
- /#/lessons?goal=exam&exam=ЕГЭ — ЕГЭ.
- /#/#price и /#/#faq — разделы главной.
- /#/direction/:id — совместимость со всеми семью прежними направлениями.
- неизвестный маршрут — экран 404.

HashRouter позволяет открывать ссылки без серверных правил переадресации. Выбор хранится в Redux в пределах текущего сеанса приложения; ссылка в Telegram содержит выбранные параметры, сообщение автоматически не отправляется.

## Редактирование

Цена и Telegram: src/shared/config/site.ts. Каталог: src/entities/lesson/model/catalog.ts. FAQ: src/widgets/faq/faq.tsx. Реальные анкеты пока не предоставлены, это явно указано в FAQ. Нет вымышленных отзывов, результатов и гарантий.

Исследование и обоснование дизайна: docs/design-research.md.

## Проверки

```sh
pnpm exec oxlint src
node scripts/verify.mjs
pnpm build
```

Проверяются TypeScript, сборка, совместимость выбора, переключение экзамена, сброс, Telegram-ссылка и обработка неизвестных старых маршрутов. Предыдущая версия проверена в браузере на мобильной, планшетной и настольной ширине. В текущей цветной итерации проверены сборка, типы, lint и модель выбора; повторная браузерная проверка жестов не выполнялась.

Выбор занятий и FAQ загружаются отдельными чанками. Manrope и WebP хранятся локально. Учтён prefers-reduced-motion.

Для ОГЭ и ЕГЭ в текущем каталоге доступна только информатика; остальные предметы отмечены как направления в поиске преподавателей. Реальные имена и достижения преподавателей не выдумываются: карточки используют понятные плейсхолдеры до подтверждения данных.

Горизонтальные направления используют существующий components/ui/carousel (Embla). Клавиатура, мышь и сенсорное перетаскивание; стрелок и автопрокрутки нет.
