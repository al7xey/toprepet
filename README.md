# TopRepet

TopRepet — сервис индивидуальных онлайн-занятий для школьников. Он помогает выбрать направление обучения, познакомиться с преподавателями и связаться с поддержкой в удобном мессенджере.

Первое знакомство с репетитором длится 20 минут и проходит бесплатно. За это время ученик и преподаватель обсуждают цель, подходящий формат и дальнейший план. После знакомства можно перейти к индивидуальным занятиям по школьным предметам, подготовке к ОГЭ и ЕГЭ, разбору домашних заданий или подготовке к школе.

## Что есть в сервисе

- Каталог направлений и школьных предметов.
- Анкеты преподавателей с фотографиями, достижениями и описанием занятий.
- Подбор занятий по цели, предмету, классу и экзамену.
- Отдельная страница бесплатного знакомства.
- Расчёт стоимости и поддержка промокодов.
- Связь с поддержкой через Telegram, WhatsApp, VK и MAX.
- Ответы на частые вопросы об оплате, переносах и формате занятий.

## Основные страницы

- `/#/` — знакомство с сервисом, направлениями и преподавателями.
- `/#/lessons` — выбор подходящих занятий.
- `/#/free-intro` — бесплатное знакомство с репетитором.
- `/#/teacher/:id` — подробная анкета преподавателя.
- `/#/contact` — связь с поддержкой.

## Технологии

- **React 19** — интерфейс и переиспользуемые компоненты.
- **TypeScript** — типизация данных, компонентов и пользовательских сценариев.
- **Vite** — локальная разработка и сборка проекта.
- **React Router** — навигация между страницами.
- **Redux Toolkit** — хранение выбранного направления, предмета, класса и промокода.
- **Embla Carousel** — карусели фотографий и карточек.
- **Base UI и shadcn** — доступные интерактивные элементы интерфейса.
- **Lucide React** — иконки.
- **Manrope Variable** — основной шрифт интерфейса.
- **CSS** — адаптивная дизайн-система, светлая и тёмная темы, мобильная и десктопная компоновка.

## Структура проекта

- `src/app` — маршруты, глобальные стили и настройка приложения.
- `src/pages` — отдельные страницы сервиса.
- `src/widgets` — крупные блоки страниц: первый экран, преподаватели, FAQ, контакты и футер.
- `src/features` — пользовательские сценарии, включая выбор занятий.
- `src/entities` — данные и модели преподавателей и занятий.
- `src/shared` — общие компоненты, конфигурация и вспомогательные функции.
- `public/images` — оптимизированные изображения сайта.

## Локальная разработка

Для проекта нужны Node.js 22.13 или новее и pnpm 10.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Проверка и сборка проекта:

```sh
pnpm build
pnpm lint
```

Основные настройки цены и контактов находятся в `src/shared/config`. Каталог преподавателей расположен в `src/entities/teacher/model/catalog.ts`.
