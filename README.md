# TopRepet

TopRepet — маркетплейс частных онлайн-репетиторов. Ученик находит репетитора в каталоге, знакомится бесплатно, записывается на занятие и оплачивает его картой. Репетитор ведёт анкету, расписание, заявки и выплаты. Администратор проверяет анкеты, отзывы и споры.

## Что есть в сервисе

- Каталог репетиторов: поиск, полноэкранные фильтры (предмет, цена, бесплатное знакомство) и сортировка.
- Анкета репетитора: фото, отметка «Документы проверены», достижения, цены, свободное время и отзывы. Кнопка «Записаться» закреплена внизу экрана.
- Запись на занятие с оплатой картой, перенос, отмена, обращение о проблеме и спор с возвратом денег.
- Заявки учеников: репетиторы откликаются сами. Раздел доступен только вошедшим пользователям.
- Чаты в стиле мессенджера, контакты в сообщениях блокируются.
- Кабинеты ученика, репетитора и администратора, уведомления, сброс пароля.
- Помощь, юридические документы, блог.

## Страницы

- Гость: `/`, `/teachers`, `/teachers/:id`, `/for-repetitor`, `/help`, `/legal`, `/blog`, `/login`, `/signup`, `/reset-password`.
- Ученик: `/me/lessons`, `/me/requests`, `/me/chats`, `/me/payments`, `/me/notifications`, `/me/account`, `/book/:id`.
- Репетитор: `/tutor/lessons`, `/tutor/schedule`, `/tutor/finance`, `/tutor/profile`, `/tutor/requests`, `/tutor/reviews`, `/tutor/students`, `/tutor/chats`.
- Администратор: `/admin/disputes`, `/admin/cancellations`, `/admin/reviews`, `/admin/profiles`.

Полная карта маршрутов лежит в `src/new-design/routes`.

## Технологии

- **React 19, TypeScript, Vite 8, React Router 7** — интерфейс и сборка с предварительной отрисовкой страниц для поиска.
- **Django** (`backend/`) — API, оплата-заглушка, фоновые задачи и админская часть. Подробности в `backend/README.md` и `docs/backend.md`.
- **Playwright, Vitest, pytest** — проверки. Описание в `docs/testing.md`.
- **Manrope Variable** — основной шрифт интерфейса.

## Структура проекта

- `src/new-design` — весь сайт: страницы (`pages`), раскладки (`layout`), UI-кит (`ui`), мок API (`api`), маршруты (`routes`). Общие правила дизайна в `src/new-design/README.md`.
- `src/app` — запуск приложения, глобальные стили и вход блога.
- `src/blog`, `src/shared` — блог и общие вспомогательные модули.
- `backend` — Django-сервер.
- `e2e` — сквозные тесты в браузере.
- `docs` — тестирование, скорость, аналитика, архитектура бэкенда.

## Локальная разработка

Нужны Node.js 22.13 или новее и pnpm 10.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

По умолчанию сайт работает на моке API с данными в `localStorage`. Демо-аккаунты (пароль у всех `demo`): ученик `olga@mail.ru`, репетитор `anastasia@toprepet.ru`, администратор `admin@toprepet.ru`.

Чтобы открыть блог по адресу `http://127.0.0.1:5173/blog`, держите репозиторий `toprepet-blog` в соседней папке (`npm ci`) и запустите `pnpm dev:all`. Supabase нужен для существующих статей и входа в админку блога; переменные задаются в `../toprepet-blog/.env.local`.

## Проверки

```sh
pnpm lint                        # линтер
pnpm exec tsc --noEmit           # типы
pnpm test                        # модульные тесты
pnpm build:e2e && pnpm e2e       # сборка и тесты в браузере (телефон 390 и компьютер 1440)
bash backend/scripts/contract.sh # те же сценарии против настоящего Django
```

Полная сборка для публикации — `pnpm build` (в конце синхронизирует блог, поэтому нужен доступ к сети).
