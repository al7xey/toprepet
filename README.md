# TopRepet

Новая версия сайта сервиса частных репетиторов. React 19, TypeScript, React Router 7, Redux Toolkit, Vite 8. Все занятия: 1 200 ₽ / 60 минут. Бесплатное короткое знакомство. Контакт: https://t.me/a17xey.

## Запуск

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm build
pnpm start
```

## FSD

- src/app: инициализация React, провайдеры, роутер, store, общие стили.
- src/pages: главная и динамически загружаемая страница направления.
- src/widgets: крупные самостоятельные блоки страницы.
- src/features/filter-directions: состояние фильтра Redux Toolkit и управление им.
- src/entities/direction: тип, данные семи направлений и карточка.
- src/shared: конфигурация цены и контакта, общие UI-элементы. Адаптер accordion переиспользует имеющийся компонент из components/ui.

Зависимости направлены вниз по слоям. Каталог установленных UI-примитивов оставлен за пределами продуктовых слоёв; в сборку попадают только используемые модули. Приложение статическое: старые формы и API удалены, база данных не требуется.

## Маршруты

- /#/ — главная.
- /#/direction/oge — пример страницы направления.
- /#/#price — раздел стоимости.
- неизвестный маршрут — экран 404.

HashRouter позволяет обновлять и открывать ссылки без серверных правил переадресации. Все семь идентификаторов находятся в src/entities/direction/model/directions.ts.

## Редактирование

Цена и Telegram — src/shared/config/site.ts. Направления — src/entities/direction/model/directions.ts. FAQ — src/widgets/faq/faq.tsx. Реальные анкеты преподавателей пока не предоставлены; на сайте размещён явный плейсхолдер. Нет вымышленных отзывов, результатов или гарантий.

Исследование и обоснование дизайна: docs/design-research.md.

## Проверки

pnpm build проверяет TypeScript и собирает production. pnpm exec oxlint src проверяет продуктовые исходники. node scripts/verify.mjs проверяет данные, Redux-фильтры, цену, URL Telegram и серверный рендер карточек. Проверка в браузере в этой итерации не выполнялась.
