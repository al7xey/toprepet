# TopRepet

Адаптивный сайт сервиса частных репетиторов. React / Vinext, Sites, D1.

## Запуск

- `pnpm install`
- `pnpm dev` — локальный сайт на 127.0.0.1:3000.
- `pnpm build` — сборка для Sites.
- `pnpm exec tsc --noEmit` — проверка типов.

## Содержание

`app/toprepet.tsx` — разделы, тексты, плейсхолдеры преподавателей и контактов.
`app/globals.css` — оформление с мобильной базы.
`app/request-form.tsx` — форма и её состояния.
`lib/request-validation.ts` — направления и проверка контактов.
`app/api/requests/route.ts` — сохранение заявки в D1; GET отсутствует, личные данные не выдаются посетителям.
`db/schema.ts`, `drizzle/` — таблица заявок и миграция.

Заявки сохраняются в таблице `requests`. Повтор запроса с тем же UUID не создаёт дубликат. Поля проверяются на клиенте и сервере, отправка требует согласия. Автоматические уведомления и панель обработки заявок не подключены; для их настройки нужен канал получения заявок владельца.

Перед открытием сайта посетителям замените плейсхолдеры анкет (включая фотографии), телефона, электронной почты и адресов Telegram/WhatsApp реальными данными. Фотография ноутбука — оригинальное изображение, созданное для дизайна, не фотография преподавателя. Никаких вымышленных отзывов, результатов, стажа или обещаний баллов нет.

## Проверка

Проверены мобильное меню, якорные переходы, выбор направления, невалидный контакт, согласие, успешная запись в локальную D1, отсутствие публичного GET заявок. Тестовые данные находятся только в локальной базе `.wrangler/`, которая не публикуется.
