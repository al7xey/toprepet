# TopRepet

TopRepet — сервис индивидуальных онлайн-занятий для школьников. Он помогает выбрать направление обучения, познакомиться с преподавателями и связаться с поддержкой в удобном мессенджере.

Первое знакомство с репетитором длится 20 минут и проходит бесплатно. За это время ученик и преподаватель обсуждают цель, подходящий формат и дальнейший план. После знакомства можно перейти к индивидуальным занятиям по школьным предметам, подготовке к ОГЭ и ЕГЭ, разбору домашних заданий или подготовке к школе.

## Что есть в сервисе

- Каталог направлений и школьных предметов.
- Анкеты преподавателей с фотографиями, достижениями и описанием занятий.
- Подбор занятий по цели, предмету, классу и экзамену.
- Отдельная страница бесплатного знакомства.
- Расчёт стоимости и поддержка промокодов.
- Связь с поддержкой через Telegram, WhatsApp, VK и MAX.
- Ответы на частые вопросы об оплате, переносах и формате занятий.

## Основные страницы

- `/` — знакомство с сервисом, направлениями и преподавателями.
- `/lessons/` — выбор подходящих занятий.
- `/free-intro/` — бесплатное знакомство с репетитором.
- `/teachers/` — каталог преподавателей.
- `/teachers/:id/` — подробная анкета преподавателя.
- `/contact/` — связь с поддержкой.

## Технологии

- **React 19** — интерфейс и переиспользуемые компоненты.
- **TypeScript** — типизация данных, компонентов и пользовательских сценариев.
- **Vite** — локальная разработка и сборка проекта.
- **React Router** — навигация между страницами.
- **Redux Toolkit** — хранение выбранного направления, предмета, класса и промокода.
- **Embla Carousel** — карусели фотографий и карточек.
- **Base UI и shadcn** — доступные интерактивные элементы интерфейса.
- **Lucide React** — иконки.
- **Manrope Variable** — основной шрифт интерфейса.
- **CSS** — адаптивная дизайн-система, светлая и тёмная темы, мобильная и десктопная компоновка.

## Структура проекта

- `src/app` — маршруты, глобальные стили и настройка приложения.
- `src/pages` — отдельные страницы сервиса.
- `src/widgets` — крупные блоки страниц: первый экран, преподаватели, FAQ, контакты и футер.
- `src/features` — пользовательские сценарии, включая выбор занятий.
- `src/entities` — данные и модели преподавателей и занятий.
- `src/shared` — общие компоненты, конфигурация и вспомогательные функции.
- `public/images` — оптимизированные изображения сайта.

## Локальная разработка

Для проекта нужны Node.js 22.13 или новее и pnpm 10.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Чтобы локально открыть блог по адресу `http://127.0.0.1:5173/blog`, держите репозиторий `toprepet-blog` в соседней папке, установите в нём зависимости (`npm ci`) и запустите из этого репозитория:

```sh
pnpm dev:all
```

Команда запускает Vite на 5173 и Next.js блога на 3001; Vite направляет `/blog` на локальный Next.js. Vercel для локальной работы не нужен. Supabase требуется для существующих статей и входа в админку; его переменные задаются в `../toprepet-blog/.env.local`.

Проверка и сборка проекта:

```sh
pnpm build
pnpm lint
```

Основные настройки цены и контактов находятся в `src/shared/config`. Каталог преподавателей расположен в `src/entities/teacher/model/catalog.ts`.

## Новый сервис: маркетплейс репетиторов (`service/`)

В папке `service/` — отдельное приложение TopRepet-маркетплейса: каталог и анкеты, запись и оплата, заявки, сообщения, уроки и споры, анкета репетитора, финансы и админка. Экраны сделаны по макету (9 сценариев, пользовательские истории 1.1–9.11) и UI-киту; стили маршрутов лежат в `service/src/styles/route-1.css` … `route-9.css`.

Сейчас сервис работает без сервера: вся бизнес-логика в `service/src/api/`, данные хранятся в `localStorage` браузера, а часы можно сдвигать, чтобы проверить сроки (24 ч на подтверждение, 4 ч на бесплатную отмену, списания серий, переводы).

### Запуск

```sh
pnpm install --frozen-lockfile
pnpm service:dev        # http://127.0.0.1:5180
pnpm service:typecheck  # проверка типов
pnpm service:build      # сборка в dist-service/
```

### Тестовые карты

| Номер | Что произойдёт |
| --- | --- |
| `2200 0000 0000 0004` | оплата проходит |
| карта на `…0002` | банк отклоняет оплату (недостаточно средств) |
| карта на `…0069` | срок действия карты истёк |
| карта на `…0341` | заморозка проходит, но плановые списания серии не проходят |
| карта выплат на `…0000` | перевод репетитору не проходит (карта закрыта) |

Срок и CVC — любые корректные. Промокоды: `ОСЕНЬ`, `ЮТАНОВО` (скидка 300 ₽ за счёт сервиса).

### Где менять заглушки на настоящие сервисы

- **Supabase (данные).** Хранилище — `service/src/api/store.ts`: `getDb()` читает весь набор данных, `mutate()` меняет его атомарно, `useDb()` подписывает экраны на изменения. Модель — `service/src/api/types.ts`, она один в один ложится на таблицы. Функции в `api/*.ts` (`booking`, `requests`, `chat`, `reviews`, `tutors`, `students`, `auth`) — это будущие серверные эндпоинты или RPC: проверки прав и правил уже внутри, экраны вызывают только их. Фоновые задачи из `api/scheduler.ts` (автоотмена через 24 ч, напоминания, списания серий, переводы, письма о непрочитанном) нужно перенести в cron или Edge Functions. Файлы чата, скриншоты споров и документы сейчас хранятся как data URL или только именем — в рабочей версии их место в Supabase Storage.
- **ЮKassa (платежи).** Шлюз — `service/src/api/gateway.ts`: `authorize()` — заморозка (холд) при записи, `chargeSaved()` — списание с сохранённой карты для серий, `payoutTo()` — перевод репетитору. Движение денег по уроку (hold → charge / release / refund) собрано в `paymentOp()` в `service/src/api/booking.ts`. Ввод карты (`PayMethods` в `service/src/ui/domain.tsx`) заменяется на виджет ЮKassa, а СБП — на её платёжную ссылку. Выплаты самозанятым — через ЮKassa Выплаты и партнёрство в «Моём налоге».
- **Яндекс ID (вход).** `service/src/api/auth.ts`: `YANDEX_CLIENT_ID` берётся из `VITE_YANDEX_CLIENT_ID`, `yandexAuthorizeUrl()` и `fetchYandexProfile()` уже ходят в OAuth Яндекса, экраны — `pages/auth/YandexAuth.tsx` и `YandexRole.tsx`. Без ключа работает демо-вход. Хеш пароля в `lib/sha256.ts` — временная мера до Supabase Auth.
- **Почта.** Письма создаёт `sendEmail()` в `service/src/api/core.ts` и складывает в `db.emails`; в рабочей версии здесь вызов почтового сервиса (например, Supabase + Resend или Unisender).
