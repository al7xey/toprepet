## Применение к TopRepet

Требования владельца и `src/new-design/README.md` приоритетны: переиспользовать `src/new-design/ui`, Manrope, существующие цвета, плоские поверхности и текущие маршруты. Не создавать новую дизайн-систему, не переносить Vite на Next.js и не вводить микросервисы из-за универсальных примеров навыка. Сначала проверить уже реализованный компонент/API. Новые кабинеты загружать лениво, ошибки/пустые состояния/ожидание делать через общий UI kit. Изменения прав проверять на сервере.

Название «Codex Design» не найдено как отдельный установленный skill/plugin; не выдавать Frontend Design или Product Design за этот продукт. Для точной интеграции нужна идентификация источника владельцем.
