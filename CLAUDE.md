# TopRepet: требования и правила работы

Файл хранит все требования заказчика. Новые замечания дописываются сюда сразу, как только они прозвучали, и учитываются на всех экранах.

## Ветки и публикация

- Новый сервис (маркетплейс репетиторов) развивается только в ветке `feature/new-service`, в папке `service/`.
- Ничего не вливать и не пушить в `main`, PR в `main` не открывать.
- Коммитить по блокам с понятными сообщениями, пушить только в `feature/new-service`.
- Ветка выкладывается на Vercel как превью: `vercel.json` и `scripts/vercel-build.mjs` собирают для неё сервис, а не лендинг.

## Запуск и проверка

- `pnpm service:dev` — порт 5180, `pnpm service:typecheck` — типы, `pnpm service:build` — сборка.
- После каждого блока: typecheck без ошибок и проверка экранов на ширине 375 и 1280 (демо-панель внизу справа: вход под Ольгой, Анной, админом, сдвиг времени).
- Экономить токены: не перечитывать понятные файлы целиком, пользоваться поиском.
- Работу по экранам сдавать по порядку: сначала главный, отправить на проверку, потом остальные.

## Стиль: ориентир — основной проект TopRepet

Не делать с нуля. Основной проект (`src/`, сайт toprepet.vercel.app) — главный образец, а для сервиса добавляются новые UI-блоки на его основе. Слой `service/src/styles/main-look.css` приводит сервис к стилю основного проекта.

- Цвета основного проекта: текст `#202838`, приглушённый `#756a68`, акцент `#f26a2e` (hover `#d9551d`), мягкий акцент `#fff0df`, поверхность `#fff7f1`, линии `#f0e2d8`.
- Фон сайта белый (`#fff`). `--bg` — только мягкая заливка внутри карточек и полей.
- Шрифт Manrope Variable, заголовки лёгкие (вес около 620, плотный межбуквенный интервал), компактная шкала шрифтов из макета.
- Блоки главной сохраняют порядок и вид основного проекта: первый экран «Топ репет — топ результат», «Выберите занятия» (карусель), «Как всё устроено» (оранжевая вертикальная шкала), «Топ репеты», «Познакомьтесь до первого занятия», «100% гарантия возврата средств», блок для репетиторов, «Вопросы и ответы», подвал.
- Кнопки и поля на лендинге-стиле: скругление 16–22 px, оранжевая основная кнопка, светлая вторичная. Поиск «Предмет, тема или репет» — прямоугольник с оранжевой кнопкой «Найти».
- Тексты по-русски, как в макете; цены с неразрывными пробелами (`nb`, `fmtMoney`); склонение имён — `lib/names.ts`.
- Время показывать в часовом поясе зрителя с подписью про пояс собеседника.

## Шапка

- Круглая плашка-капсула с логотипом и кнопками («Войти» и т. д.), всегда на экране, в том числе при прокрутке (sticky, на любой ширине, и на телефоне).
- Эффект liquid glass: полупрозрачный фон, сильное размытие, подсветка краёв.
- Стекло только у того, что висит поверх контента: шапка, таб-бар, нижняя панель действий, тост.
- На внутренних экранах телефона — appbar с кнопкой «Назад».
- Не использовать `overflow-x: hidden` на предках шапки: он ломает sticky (использовать `overflow-x: clip`).

## Карточки репетиторов

- Крупные: на телефоне две колонки, высокие; на компьютере от 280 px шириной.
- Плашка на карточке — как в основном проекте: беж `rgb(255 249 244 / 86%)`, размытие 18 px, граница `#ffffffbb`, радиус около 25 px, текст по центру: предмет полужирным цветом `#202838`, ниже приглушённая строка с именем, оценкой и ценой.
- Не показывать «новый преподаватель» ни в карточках, ни в анкетах.
- На главной нет отдельной большой карточки одного репетитора вверху.
- Репетиторы с настоящими фото показываются раньше демо-аккаунтов с заглушками.

## Бизнес-логика и данные

- Вся логика в `service/src/api/` с хранением в `localStorage`; страницы вызывают только функции из `api`.
- Менять заглушки на Supabase, ЮKassa, Яндекс ID по инструкции в README (раздел про `service/`).
- Демо-аккаунты с паролем `demo12345`; тестовые карты `2200 0000 0000 0004` (успех), на `…0002` (отказ банка), `…0341` (не пройдут списания серий).
- При изменении демо-данных поднимать `DB_VERSION` в `api/store.ts`.
