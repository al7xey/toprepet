# Правила работы над TopRepet

Для любых изменений интерфейса обязательно сначала читать `docs/design-rules.md`.
Это согласованный с владельцем стандарт для предстоящей переработки всех страниц.
Текущий внешний вид сайта не является эталоном. Существующие ошибки нельзя сохранять
только ради совместимости с текущими CSS или компонентами. Проверять компоненты перед
переиспользованием; исправлять общую причину, а не копировать локальные исключения.

Перед реализацией ответить на вопросы раздела «До изменения», определить роли,
компоненты, текстовые стили и отступы. Перед завершением заполнить проверку раздела
«После изменения» с фактическим результатом. Непроверенное отмечать явно; не заявлять
идеальность, полное соответствие или визуальную проверку без доказательств.
Одинаковые элементы одной роли и плотности должны иметь одинаковые отступы,
типографику, размеры, состояния и поведение. Исключения должны иметь причину.

При конфликте с прежними описаниями внешнего вида применять новые требования владельца
и `docs/design-rules.md`; не менять стек ради универсальных рекомендаций.

Публикация: preview находится в отдельном репозитории `al7xey/toprepet-preview`,
который собирает ветку `codex/liquid-glass`. Основной `toprepet.ru` публикуется из
`main`. Не возвращать объединённую публикацию preview под основным доменом.
