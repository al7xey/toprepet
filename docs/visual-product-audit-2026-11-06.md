# Визуальное обновление и готовность продукта — 6 ноября 2026

Ветка `design/home-mockup`. Этот проход добавляет визуальные улучшения к предыдущим аудитам качества и SEO/GEO. Сохранены Manrope, чёрно-оранжевая палитра, плоские поверхности, общий UI kit и работающие маршруты.

## Что изменено

- На главной добавлен выбор из шести предметов. Это настоящие ссылки на каталог с действующим фильтром; они сохраняют возможность открыть страницу в новой вкладке и работают без отдельного состояния JavaScript. Выбор использует существующее аналитическое событие teacher_filter с разрешённым названием предмета.
- Компонент «Как всё устроено» на широком экране складывается в горизонтальный маршрут из четырёх шагов; на узких экранах сохраняет вертикальную последовательность. Использован существующий Steps.
- Для блока знакомства создана оригинальная редакционная иллюстрация в стиле сайта. Она показывает условный сценарий разговора ученика с преподавателем, а не настоящий интерфейс видеосвязи. Адаптивные WebP: 640 px — 34 734 байта, 960 px — 59 814 байт; браузер выбирает один подходящий файл. Размеры зарезервированы, загрузка отложенная. Исходный PNG сохранён среди артефактов сессии.
- Блок знакомства получил композицию из изображения и трёх пояснений с существующими иконками и кнопкой. Кнопка теперь открывает каталог с intro=1, сохраняя обещание бесплатного знакомства.
- Изображение первого экрана страницы для преподавателей получило srcSet/sizes с уже существующими вариантами 640/1200 px.

## Анимации

Добавлены однократные появления блоков и последовательное появление шагов через Web Animations API. Длительность 420 мс, ограниченная задержка до 240 мс. Меняются только opacity и transform. Блоки с интерактивными элементами используют только прозрачность, сохраняя положение кнопок и полей. Бесконечного покачивания, автопрокрутки и тяжёлой библиотеки нет.

Контент исходного HTML виден без JavaScript. Уже показанный первый экран пререндера остаётся стабильным при гидрации. Анимации появляются при последующей прокрутке и переходах. Настройка prefers-reduced-motion учитывается и при загрузке, и при её изменении. Фокус отменяет движение затронутого блока; наблюдатели и анимации очищаются при удалении элементов и размонтировании. Удалены старые правила rv-on, скрывавшие содержимое через CSS.

## Исправленные ошибки

| Проблема | Исправление |
|---|---|
| Главная и страница для преподавателей молча сохраняли подборку из снимка сборки при сбое API | Общий TutorShowcase показывает ошибку с повтором, загрузку или действительные данные; для пустого ответа есть отдельное состояние |
| Создание ученической заявки показывалось преподавателю и администратору | Публичная кнопка учитывает роль; гостю доступен вход с возвратом к заявке |
| Вошедший пользователь попадал с кнопки создания анкеты на регистрацию, которая возвращала его в прежний кабинет | Кнопки явно предлагают переход в доступный кабинет; администратору не предлагается недоступная лента заявок |
| Кнопка знакомства вела в общий каталог без условия | Переход сохраняет intro=1 |

## Проверки

- Проверяются все шесть предметных переходов, условие знакомства, действия ученика/преподавателя/администратора и настоящие вызовы анимаций с переключением reduced motion.
- Проверены размеры 320/768/1440 px, границы новых блоков и загрузка изображения. Снимки экрана просмотрены; изображение и маршрут шагов согласованы с существующим дизайном.
- Отдельный сценарий с Django возвращает 503 для подборок на обоих лендингах и проверяет ошибку, отсутствие устаревших карточек и восстановление после повтора.
- Общий прогон проверяет доступность, связность внутренних ссылок, формы, запись, сообщения, документы и кабинеты. Итоговые CI-результаты следует смотреть у коммита с этим отчётом.

## SEO, GEO и аналитика

Уже установленные seo-audit и ai-seo применены повторно. Сохраняются title/description, canonical, Open Graph, sitemap, robots, FAQ и llms.txt. SEO-проверка охватывает публичный HTML, приватные маршруты с noindex и соответствие разметки карточкам. Новые изображения имеют описательный alt и фиксированные пропорции; предметные ссылки поддерживают внутреннюю навигацию, а фильтрованные URL канонизируются на основной каталог. Не добавлялись фиктивные рейтинги, результаты учеников или обещания позиций в поиске.

В этом сеансе нет доступа к отчётам Search Console, Вебмастера и посещаемости. Изменение органического трафика, конверсии и AI-цитирования не измерено. План измерения после выпуска находится в `seo-geo-audit-2026-11-06.md`.

|---|---:|---:|---:|

Разница между режимами мала и не доказывает ускорение из-за анимаций. Это локальные лабораторные наблюдения, а не полевые Core Web Vitals или замер production API. Разницу с прежними сериями нельзя приписывать только этому обновлению.

## Что необходимо для настоящего запуска

Визуальная готовность и успешные тесты не равны работающему приёму реальных платежей. В репозитории реализован FakeProvider; YooKassaProvider — заготовка. В production тестовая оплата заблокирована. Для реальных денег нужны выбранный провайдер, полноценная интеграция с безопасным виджетом, обработкой вебхуков и настройка секретов через защищённое окружение. Владелец получил вопрос о выборе провайдера; ключи в чат не запрашиваются.

Изменения отправляются в указанную ветку от имени alexey; опубликованный сайт обновляется из main и в этом проходе не выпускается. Также остаются внешние интеграции, эксплуатационные проверки и серверная индексация новых анкет вне статического снимка. Эти ограничения не следует скрывать за утверждением об «идеальном готовом продукте».
