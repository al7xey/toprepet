# Скорость

Замеры без Lighthouse (нет доступа к сети): Chromium с профилем «медленный 4G» (1,6 Мбит/с, 150 мс) и замедлением процессора в 4 раза, экран 390 px, медиана трёх запусков, собранный `dist` через `vite preview`. Сценарий — `perf.mjs` в рабочей папке; метрики снимаются через `PerformanceObserver` (LCP, CLS, долгие задачи для TBT).

| Страница | LCP до → после | CLS | TBT после |
|---|---|---|---|
| Главная | 1,76 → 1,62 с | 0 | 241 мс |
| Каталог | 2,80 → 1,63 с | 0,015 | 184 мс |
| Анкета | 1,36 → 1,37 с | 0 | 207 мс |
| Для репетиторов | 1,62 → 1,81 с | 0 | 225 мс |
| Помощь, документы | 1,04–1,09 с | 0 | 100–134 мс |

Что сделано:
- Две первые карточки каталога и подборок грузятся сразу с высоким приоритетом, остальные лениво (LCP каталога −1,2 с).
- Удалены старые виджеты, промокоды, игра, старый CSS и Redux: убраны лишние ~280 КБ исходного кода и 9 CSS-файлов.
- Тяжёлые части админки блога разнесены по отдельным чанкам (`editor` 471 КБ, `supabase` 214 КБ, `transliteration` 182 КБ) и грузятся только в админке; предупреждения о чанках > 500 КБ больше нет.

Что осталось (не блокирует): единый `index.css` ≈ 107 КБ (около 20 КБ в gzip) при 16% использования на главной — его можно разделить по маршрутам; TBT на главной держится около 240 мс из‑за стилей и разметки при гидрации (в замедлении ×4).
