# Иконки интерфейса

Используется базовый минималистичный чёрно-белый набор. Геометрия основных значков восстановлена из версии до мультяшного оформления. Иллюстрации, декоративные рамки и их анимации удалены.

`Icon` из `src/new-design/ui/icon.tsx` — общий компонент для меню, кнопок, форм, карточек и редактора. Значки чёрные, на заполненных кнопках действий — белые. Пустые звёзды контурные, выбранные заполнены.

Источник — `src/new-design/ui/icons.svg`. После изменения SVG выполните `node scripts/build-icons.mjs`: команда обновит `icon-artwork.tsx`. Переиспользуемые названия перечислены в генераторе. Отдельные сторонние библиотеки для значков не нужны.
