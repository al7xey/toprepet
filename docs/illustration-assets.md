# Иллюстрации TopRepet

Шесть оригинальных мультяшных сцен сгенерированы для проекта: `search`, `chat`, `calendar`, `requests`, `finance`, `achievement`. Оптимизированные WebP находятся в `public/images/scenes/`, общий размер около 237 КБ. Они используются через `Scene` в заголовках разделов и общих пустых состояниях. Персонажи декоративные, они не выдают себя за реальных преподавателей.

Одобренный мультяшный набор содержит 77 SVG. `Icon` отображает одинаковую геометрию в меню, кнопках, формах, карточках и редакторе блога. Оранжевые заливки сочетаются с чёрным контуром; на оранжевых кнопках используется белый контур. `SceneIcon` показывает рисунок без дополнительной рамки. Выбранные и пустые звёзды в форме отзыва различаются заливкой.

Исходные SVG и лист согласования находятся в `design/icon-proposal-cartoon/`. Команда `node scripts/build-icons.mjs` обновляет общий React-набор `src/new-design/ui/icon-artwork.tsx`; вручную его не редактируют. Семантические значки дипломов, языков, медалей и наград выбирает `achievementIcon`.

`scenes.css` содержит появление иллюстрации и короткое мерцание звезды. Нет бесконечной анимации; при `prefers-reduced-motion: reduce` эффекты отключены.

Оригиналы генерации сохранены в каталоге Codex `generated_images`; сайт использует только файлы из репозитория.
