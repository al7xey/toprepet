# Переработка интерфейса — 16 ноября 2026

## Решения перед реализацией

Общий язык: белый фон, Manrope, нейтральные контуры, чёрные иконки,
единый яркий оранжевый. Стекло отделяет навигацию и управление от содержимого.
Лендинги используют фотографии реальных преподавателей и последовательные шаги,
кабинеты — читаемые строки, формы и ясные статусы. Текущие CSS не являются эталоном.

| Семейство | Задача / порядок внимания / следующий шаг | Компоненты и состояния |
|---|---|---|
| Главная, для репетиторов | Предложение → способ работы → CTA | Hero, Steps, Section, CTA; мобильная вертикальная группа |
| Каталог и анкета | Предметы и фото → цена и условия → время → запись | TutorCard, фильтры, SelectField, SlotPicker; загрузка, нет результатов, ошибка |
| Вход, регистрация, код, восстановление | Название → поля → отправка → альтернативный сценарий | AuthCard, FieldWrap, Button; ошибка рядом с полем, pending, успех |
| Профили, настройки | Личность → разделы → изменение данных | NavigationRow, Avatar, Switch; возврат в источник, длинная почта |
| Уроки, запись, платежи, заявки | Статус и важные данные → допустимое действие | PageHeader, Card, Tabs, Rows; пустое, загрузка, ошибки, подтверждения |
| Чаты | Собеседник → история → ввод и отправка | Person, разделители, bubble, composer, Modal; клавиатура, переносы, жалоба |
| Анкета и документы репетитора | Готовность → данные → редактирование/сохранение | WizardProgress, Field, Card, загрузка файла; ошибки и незавершённые поля |
| Расписание и финансы | Доступность/суммы → редактирование → сохранение | Calendar, interval, Rows; длинное время, узкий экран |
| Админка | Очередь → содержимое → решение | Tabs, Card, Modal; просмотр, подтверждение, блокировка, пустая очередь |
| Помощь, блог, документы, 404 | Тема → структурированный текст → нужный переход | Section, FAQ, заголовки и ссылки; длинный текст и отсутствие данных |

Для всех семейств: общий набор отступов, размеров кнопок и ролей текста;
нет случайной смены геометрии при выборе/загрузке. Проверять 320/390/768/1440 px,
длинный текст и увеличение шрифта. Исправление общего компонента затрагивает все семейства.
Проверки: сборка/типы, существующие сценарии, обход маршрутов с DOM-геометрией,
axe и скриншоты. Отсутствие ошибок DOM не считается самостоятельной визуальной проверкой.

## Исходные находки

- `ui/kit.css`: повторные переопределения размеров кнопок и заголовков; размер подписи 19 px вне роли.
- `ui/kit.css`: карточки с полями 18/28/36 px вместо общей шкалы; плавающие gap 10/14/18 px.
- `ui/liquid-glass.css`: конкурирующие размеры мобильной шапки; grid не учитывает отсутствие кнопки входа.
- `ui/kit.tsx`: select/textarea не связывают сообщение ошибки с полем.
- `ui/kit.tsx`: disabled/loading меняет тип ссылки на button; необходимо сохранять размеры и доступные состояния.
- `tr.css`: белая подпись на ярком оранжевом требует отдельной проверки контраста.
- `layout/layouts.tsx`: мобильное меню затемняет фон, но не ограничивает фокус и скролл.
- `.github/workflows/pages.yml` в дизайн-ветке содержит устаревшее объединение preview с основным доменом.

## Результаты

Обход 108 комбинаций маршрута и размера экрана (54 адреса × 390/1440 CSS px):
0 нарушений axe WCAG A/AA по выбранным тегам, 0 ошибок JavaScript,
0 битых изображений, 0 страниц с горизонтальным переполнением.
Скриншоты и сводные листы сохранены локально в `design/review-final/`.
Это не утверждение о полной сертификации WCAG: автоматическая проверка имеет ограничения.
Последующие изменения иллюстраций лендингов и оформления откликов проверяются отдельно.

## Применённые изменения

- Вынесены канонические роли в `ui/standards.css`; удалён предыдущий конфликтующий блок шкалы в kit.css.
- Стандартные/компактные/крупные кнопки: 48/40/56 px; равные поля, неизменная геометрия состояний.
- Светлые действия используют общую поверхность; оранжевые — читаемую чёрную подпись.
- Формы получили общие поля и высоту области ввода; ошибки select/textarea связаны с контролами.
- Шапка имеет равные отступы 8 px вокруг бургера; мобильное меню блокирует фон и удерживает фокус.
- Нижняя панель сохраняет симметрию без внешней тени; граница не меняет координаты индикатора.
- Профиль, настройки, кабинет, заявка, календарь и админка используют общие роли.
- Убраны двойные отступы достижений, повторная обводка навигационного списка и коричневатые контуры.
- Лендинги используют фотографии преподавателей через общий HeroTutors.
- Отклики отделяют выбор времени от вспомогательных переходов в анкету и чат.
- Админка блога получила ту же шкалу текста, полей и кнопок.
- Устаревшая публикация preview на основном домене удалена из workflow дизайн-ветки.
