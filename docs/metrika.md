# Аналитика TopRepet

Счётчик Яндекс Метрики **112922088** восстановлен после отключения при удалении cookie-banner. Настройки счётчика в кабинете Яндекса не изменялись. Пропущенные во время отключения посещения восстановить невозможно.

Всплывающего баннера нет. На странице «Документы → Cookies» посетитель может выбрать «Принять» или «Только необходимые». Существующий сохранённый выбор совместим с прежней версией сайта. До разрешения аналитики скрипт mc.yandex.ru не загружается, события не отправляются. Посетители без разрешения не учитываются в Метрике.

Выбор хранится локально 180 дней. При недоступности localStorage явный выбор действует в памяти страницы с тем же сроком. Отказ останавливает счётчик, отменяет очередь ещё не отправленных событий и удаляет доступные сайту cookies _ym_. Уже отправленные сведения автоматически не удаляются.

На публичном домене учитываются просмотры при переходах между страницами, переходы в мессенджеры, выбор занятия и фильтров, просмотры анкет, разделов и статей, раскрытие FAQ, прокрутка и активное время. Webvisor, карта кликов и отслеживание ссылок включены после разрешения. Счётчик исключён на localhost и в /blog/admin/. Произвольные параметры URL и текст поискового ввода не передаются в цели.

SPA использует defer: true и отдельный hit для каждого нового адреса, без двойного автоматического просмотра. См. [официальную инструкцию Яндекса для SPA](https://yandex.ru/support/metrica/ru/code/counter-spa-setup).

Проверка node scripts/verify-analytics.mjs имитирует API счётчика без реальной отправки посещений: разрешение/отказ, смена маршрутов, цели, отсутствие дублей, отключение в админке, очистка очереди и срок выбора. Эта проверка включена в build. Наличие посещений в кабинете нужно проверять на реальном публичном сайте после разрешения аналитики; блокировщик рекламы может блокировать скрипт.
