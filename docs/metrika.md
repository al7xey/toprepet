# Аналитика TopRepet

Счётчик: **112922088**, основной домен: **toprepet.ru**. Настройка: 5 октября 2026.

В кабинете сохранены 20 целей JavaScript и составная воронка. Вебвизор и карты кликов включены, запись содержимого полей отключена. Включена контентная аналитика Schema.org JSON-LD. Часовой пояс — Москва. Сохранён фильтр основного домена; поведенческие роботы не удаляются из исходных данных.

На дашборд «Сводка» добавлены показатели целевых визитов с кликами учеников и репетиторов по мессенджерам. Эти две цели также добавлены в избранное. Автоцель отправки формы может срабатывать на поиск/промокод: это не заявка.

## Цели и параметры

| Событие | Назначение | Дополнительные параметры |
| --- | --- | --- |
| `contact_student_click` | Ученик кликнул по мессенджеру | messenger, teacher при обращении из анкеты |
| `contact_tutor_click` | Репетитор кликнул по мессенджеру | messenger |
| `contact_telegram`, `contact_whatsapp`, `contact_vk`, `contact_max` | Канал обращения | messenger, teacher |
| `lesson_picker_view` | Открыта страница подбора | — |
| `lesson_selection` | Выбран предмет, направление, класс или экзамен | field, choice (только значения каталога) |
| `lesson_contact_step` | Переход от выбора к менеджеру | subject_selected, grade_selected |
| `teachers_catalog_view` | Открыт каталог | — |
| `teacher_profile_view` | Открыта существующая анкета | teacher (slug) |
| `teacher_search` | Выполнен поиск | has_query, results; текст запроса не отправляется |
| `teacher_filter` | Выбран фильтр предмета | subject |
| `faq_open` | Открыт ответ FAQ | question (номер) |
| `section_view` | Раздел появился на видимом экране | section |
| `scroll_75` | Прокрутка на 75% | — |
| `engaged_60` | 60 секунд активного просмотра страницы | — |
| `blog_article_view` | Открыта статья | — |
| `blog_cta_click` | Переход из блога к подбору/знакомству | — |
| `promo_check` | Проверен промокод | applied; код не отправляется |

Во всех событиях есть `page`: home, lessons, teachers, teacher_profile, for_tutors, blog, blog_article, free_intro или other.

Воронка **«подбор → выбор → мессенджер»** (ID 669504986) использует `lesson_picker_view` → `lesson_selection` → `contact_student_click` в рамках одного визита. Прямое обращение без подбора учитывается в самостоятельной цели ученика, но не в этой воронке.

## Как смотреть результаты

- Конверсии: выбирать цель ученика либо репетитора; сравнивать источники/UTM, устройства, регионы, новые/повторные визиты.
- Параметры визитов: предметы, анкеты, разделы и каналы обращений; отделять интерес к предмету от обращения к менеджеру.
- Воронка: находить, на каком шаге подбора теряются посетители.
- Вебвизор и карта кликов: смотреть проблемные визиты из сегментов без обращения.
- Контент: сравнивать статьи, рубрики, авторов и дочтения после появления опубликованных статей. Сейчас опубликованных статей в снимке блога нет.

Метрика даёт агрегированные данные об аудитории и поведении, а не персональные личности посетителей. Нельзя суммировать цель ученика с целями отдельных мессенджеров: это одни и те же клики.

## Установка и ограничения

Единый SPA-трекер отправляет `hit` для всех публичных страниц, включая блог. Повторный эффект React не создаёт дубликат. Просмотры получают заголовок текущей страницы. Свободные параметры URL очищаются, UTM и рекламные идентификаторы сохраняются; внутренних UTM на переходе из статьи к подбору нет.

Счётчик не запускается на localhost и в `/blog/admin/`. При переходе в админку вызывается `destruct`, при возвращении — `init`. Поля поиска/промокода/произвольного описания и резервные тексты сообщений помечены классами приватности Вебвизора.

Электронная коммерция в кабинете доступна (`dataLayer`), но события покупки и доход не отправляются: сайт не подтверждает оплату. Клик по мессенджеру не подтверждает отправку сообщения или оказание услуги. Для реальных заявок, оплат и возвратов нужен обмен с CRM/платёжной системой с подтверждёнными данными.

Проверки: `node scripts/verify-analytics.mjs`, `pnpm lint`, `pnpm build`. Новые события начнут собираться после публикации изменений сайта; настройка целей не создаёт их задним числом.
