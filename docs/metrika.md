# Аналитика TopRepet

Счётчик Яндекс Метрики **112922088** восстановлен после отключения при удалении cookie-banner. Настройки счётчика в кабинете Яндекса не изменялись. Пропущенные во время отключения посещения восстановить невозможно.

Всплывающего баннера нет. Счётчик запускается автоматически на публичных страницах, без предварительного открытия документов или нажатия кнопок. На странице «Документы → Cookies» посетитель может включить или отключить аналитику. Ранее сохранённый явный отказ учитывается.

Настройка хранится локально 180 дней. При недоступности localStorage настройка действует в памяти страницы с тем же сроком. Отключение останавливает счётчик, отменяет очередь ещё не отправленных событий и удаляет доступные сайту cookies _ym_. Уже отправленные сведения автоматически не удаляются.

На публичном домене учитываются просмотры при переходах между страницами, переходы в мессенджеры, выбор занятия и фильтров, просмотры анкет, разделов и статей, раскрытие FAQ, прокрутка и активное время. Webvisor, карта кликов и отслеживание ссылок включены. Счётчик исключён на localhost и в /blog/admin/. Произвольные параметры URL и текст поискового ввода не передаются в цели.

SPA использует defer: true и отдельный hit для каждого нового адреса, без двойного автоматического просмотра. См. [официальную инструкцию Яндекса для SPA](https://yandex.ru/support/metrica/ru/code/counter-spa-setup).

Проверка node scripts/verify-analytics.mjs имитирует API счётчика без реальной отправки посещений: автоматический запуск для нового посетителя, отсутствие баннера, включение/отключение, смена маршрутов, цели, отсутствие дублей, отключение в админке, очистка очереди и срок настройки. Эта проверка включена в build. Наличие посещений в кабинете нужно проверять на реальном публичном сайте; блокировщик рекламы может блокировать скрипт.
