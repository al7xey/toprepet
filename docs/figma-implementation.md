# Реализация по дизайну: главный экран

Ветка: `feature/figma-faithful-implementation`. Первый этап: главная страница `/` по макету.

## Источники дизайна

| Материал | Где | Статус |
|---|---|---|
| User Flow | FigJam: https://www.figma.com/board/TkPSNURO4taYJrOOZqGlvc | 3 диаграммы (знакомство, бронирование и оплата, кабинеты) |
| Wireframes | https://claude.ai/artifact/SAuHaWsYyWZZN26MAdrLQ1 | 9 маршрутов, телефон и компьютер |
| UI Kit v15 | https://claude.ai/artifact/8tJWGg9uJiQXXqu1zPoR2f | HTML, не Figma |
| Финальные макеты | https://claude.ai/artifact/8Srvn7ZBdphSVP1GugEndB | 98 экранов, HTML, компактная шкала шрифтов |

Макеты и UI Kit сделаны в HTML, а не в Figma: аккаунт Figma на тарифе Starter с View-местом, и MCP упирается в лимит вызовов. Поэтому размеры, цвета и отступы взяты из CSS макетов.

## Архитектура

- `src/shared/ui/kit/`: дизайн-система.
  - `kit.css`: токены (цвета, стекло, радиусы, шрифт) и стили компонентов. Классы начинаются с `tr-`, токены с `--tr-`, всё живёт внутри `.tr`, поэтому старые стили лендинга не задеты.
  - Компоненты: `Button`, `Icon`, `SiteHeader`, `SearchBar`, `TeacherCard` и `TeacherGrid`, `DirectionTiles`, `InfoCard`, `StepCards`.
  - `routes.ts`: куда ведут действия макета.
- `src/pages/home/`: новая главная (`home-page.tsx`, `home-page.css`, `home-data.ts`). Старые виджеты главной не удалены, их используют другие страницы.
- `src/app/app.tsx`: на `/` старая шапка не рендерится, главная показывает шапку UI kit сама. Футер пока старый, в макете главной его нет.

Брейкпоинт телефон/компьютер: 760 px, как в остальном коде.

## Открытые вопросы (противоречия макета и текущего продукта)

1. **Рейтинг и отзывы на карточках.** В каталоге (`entities/teacher`) рейтингов и отзывов нет. Вместо них на плашке выводится опыт: «Анна · 1–3 года».
2. **Цена «от …».** В макете у каждого репетитора своя цена. На сайте цена одна, `PRICE` = 1 200 ₽. На карточках сейчас «от 1 200 ₽».
3. **«Войти» и «Создать заявку».** Входа и мастера заявок пока нет. Обе кнопки временно ведут на `/lessons/`, адреса заданы в `kit/routes.ts`.
4. **Направления для взрослых** («Языки», «Работа и карьера», «Высшее образование», «Хобби и творчество»). В `/lessons/` их нет, поэтому они ведут в каталог `/teachers/`.
5. **Картинки направлений.** В макете на месте фото цветные плитки из UI kit. Реальных фото направлений в репозитории нет, поэтому оставлены цветные плитки.
6. **Сердечко у гостя.** По макету оно должно вести на вход. Пока сердечко просто переключается на месте.
7. **Поиск** отправляет на `/teachers/?q=…`, но каталог параметр `q` пока не читает.
