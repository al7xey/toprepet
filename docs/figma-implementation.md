# Реализация по дизайну: главный экран

Ветка: `feature/figma-faithful-implementation`. Первый этап: главная страница `/` по макету.

## Источники дизайна

| Материал | Где | Статус |
|---|---|---|
| User Flow | FigJam: https://www.figma.com/board/TkPSNURO4taYJrOOZqGlvc | 3 диаграммы (знакомство, бронирование и оплата, кабинеты) |
| Wireframes | https://claude.ai/artifact/SAuHaWsYyWZZN26MAdrLQ1 | 9 маршрутов, телефон и компьютер |
| UI Kit v15 | https://claude.ai/artifact/8tJWGg9uJiQXXqu1zPoR2f | HTML, не Figma |
| Финальные макеты | https://claude.ai/artifact/8Srvn7ZBdphSVP1GugEndB | 98 экранов, HTML, компактная шкала шрифтов |

Макеты и UI Kit сделаны в HTML, а не в Figma: аккаунт Figma на тарифе Starter с View-местом, и MCP упирается в лимит вызовов. Поэтому размеры, цвета и отступы взяты из CSS макетов.

## Архитектура (после замечаний 2026-10-09)

Первая версия главной была собрана с нуля из UI kit. Владелец попросил ориентироваться на основной проект и добавлять только новый UI. Поэтому:

- Главная состоит из блоков основного проекта (`src/widgets/*`). Блок «Вы репетитор?» убран.
- Новый UI: шапка-капсула liquid glass с кнопкой «Войти» (`src/widgets/header/header.tsx`, `header.css`), она общая для всех страниц.
- Карточки репетиторов на главной крупнее (`src/pages/home/home-page.css`), плашка осталась как в основном проекте.
- Все требования владельца собраны в `CLAUDE.md`.

## Открытые вопросы (противоречия макета и текущего продукта)

1. **Рейтинги, отзывы и индивидуальные цены.** В каталоге (`entities/teacher`) их нет, поэтому карточки показывают только предметы, как в основном проекте. Цена на сайте одна, `PRICE` = 1 200 ₽.
2. **«Войти».** Страницы входа ещё нет. Кнопка временно ведёт на `/lessons/`, адрес задан в `LOGIN_PATH` (`src/shared/config/site.ts`).
3. **Заявки, избранное, кабинеты** из макетов пока не реализованы.

## Предложения (не внесены)

- Поиск в первом экране главной и кнопка «Создать заявку» из макета.
- Футер в стиле UI kit для всех страниц.

## Обновление 2026-10-09 (весь UI по макету)

- Добавлен сквозной слой `src/app/ui-kit.css` (подключается последним): шкала шрифтов 15 px, кнопки-капсулы 46 px, одна оранжевая кнопка (вторичные: бежевая заливка/серая), поля и поиск капсулами, карточки с радиусом 24–32 и тонкой тенью, выбранный чип: белый с оранжевой обводкой, белый фон.
- Главная по порядку макета: герой с поиском и «Подобрать репетитора» / «Создать заявку», «Выберите занятия» (карточки-строки в 2 ряда), «Топ репеты», «Как всё устроено» (4 карточки), «Познакомьтесь до первого занятия» + «Гарантия возврата» парой, затем цена, контакты, FAQ основного сайта.
- Поиск из героя ведёт на `/teachers/?q=…` (страница каталога читает `q`).
